Projetos em Andamento
1. Aplicação Web para Análise Diacrônica de Termos
Desenvolvimento de uma ferramenta web para o rastreamento e análise da evolução de termos e expressões linguísticas ao longo das décadas, utilizando processamento de linguagem natural.

Pesquisadores: Larissa Pavan, Thiago Serra, Beatriz Mayumi e Guilherme de Carvalho.
2. Análise Computacional das Letras dos Beatles
Experimento prático focado na aplicação de técnicas de PLN, como lematização e cálculo de TF-IDF, para analisar o vocabulário e a complexidade das letras da banda ao longo de suas diferentes fases e álbuns.

Pesquisadores: Larissa Pavan, Thiago Serra, Beatriz Mayumi e Guilherme de Carvalho.
